# Sample data

Shipped starter files copied into `data/` on first run (only if missing):

- `players.db` — NBA player cache with season/news/injuries stats. Fantasy owners are anonymized (`FA` / `W (…)` / `Taken`). No personal notes or watchlist.
- JSON stubs for meta/rules/standings/roster/matchups — empty until you run **Refresh** against your Yahoo league.

Your live `data/` folder stays local and is gitignored.
